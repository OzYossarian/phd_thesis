\section{The Focked up ZX-calculus}

With the basic algebra of continuous-variable quantum information theory covered, we can switch to a graphical approach via the Focked up ZX-calculus.

\subsection{Generators}

As with qubits, one can just think of these ZX-diagrams as being really good notation for linear maps.
Whereas for qubits we started with the green and red spiders, for qumodes we will start with the Fock spider:
\begin{align}\label{eq:fock_spider_defn}
    \tikzfig{qumodes/prelims/zx/spider_fock_braces}
    \quad &= \quad
    \sum_{n \in \NN_0} f(n) \ket{n}_F^{\otimes m}\bra{n}_F^{\otimes l}
\end{align}
Here $f$ can be any function $\NN_0 \to \CC$.
Throughout, we will use the shorthand $\isarg{x}$ to denote that $x$ is the variable in a single-argument function.
For example, the expression $i^{\isarg{n}}$ is a shorthand for the function $n \mapsto i^{n}$.
Examples of familiar objects defined using the Fock basis are:
\begin{equation}\label{eq:fock_spider_examples}
    \tikzfig{qumodes/prelims/zx/state_fock} ~~=~~ \ket{m}_F
    \qqquad
    \tikzfig{qumodes/prelims/zx/fourier_transform} ~~=~~ \mathcal{F}
    \qqquad
    \tikzfig{qumodes/prelims/zx/fourier_transform_inverse} ~~=~~ \mathcal{F}^{-1}
\end{equation}
Anytime the function label is omitted from a spider, it means the function is the map $x \mapsto 1$.
Next we introduce the green and red spiders:
\begin{align}\label{eq:green_and_fock_spiders_defn}
    \tikzfig{qumodes/prelims/zx/spider_green_braces}
    \quad &= \quad
    \int_{\mathbb{R}} dq\ f(q) \ket{q}_Q^{\otimes m} \bra{q}_Q^{\otimes l} \\
    \tikzfig{qumodes/prelims/zx/spider_red_braces}
    \quad &= \quad
    \int_{\mathbb{R}} dp\ g(p)\ket{p}_P^{\otimes m}\bra{p}_P^{\otimes l}
\end{align}
Here $f$ and $g$ are any functions $\mathbb{R} \to \mathbb{C}$.
These two spiders are related via Fourier transforms; graphically, this is:
\begin{equation}\label{eq:green_red_spiders_related}
    \tikzfig{qumodes/prelims/zx/spider_red}
    \quad=\quad
    \tikzfig{qumodes/prelims/zx/spider_green_fouriered}
\end{equation}

Importantly, unlike in the qubit case, the green cup is not equal to the red cup:
\begin{equation}
    \tikzfig{qubits/prelims/zx/state_bell_green}
    ~~\neq~~

So whereas in the qubit case we could define the `spiderless' cup to be the green or red cup without any problems, we can't do this for qumodes.
There are multiple ways to handle this -- the most common is just to define the spiderless cup to be the green cup.
We won't take this approach -- we'll instead forbid cups and caps from being spiderless.
Whatever resolution we choose, a consequence is that we lose the very desirable property that only connectivity matters!
For example, we can no longer draw (the CV analogue of) the CNOT gate with a vertical edge, because it's ambiguous which of two unequal diagrams this would mean:

\end{equation}

The final non-trivial generator we'll need is the multiplier:
\begin{equation}\label{eq:multiplier_defn}
    \tikzfig{qumodes/prelims/zx/multiplier}
    \quad = \quad
    \int_{\mathbb{R}} dq\ \ket{mq}_Q \bra{q}_Q
\end{equation}
This can be expressed in terms of existing generators:
\begin{equation}
    \tikzfig{qumodes/prelims/zx/multiplier}
    \quad = \quad
    \begin{cases}
        \tikzfig{qumodes/prelims/zx/multiplier_decomposed_m} &\text{ if $m \neq 0$} \\[5pt]
        \tikzfig{qumodes/prelims/zx/multiplier_decomposed_0_padded} &\text{ if $m = 0$}
    \end{cases}
\end{equation}

As with qubits, vertical and horizontal composition of diagrams correspond respectively to tensor products and composition of linear maps.
Conjugation of a diagram corresponds to conjugating all labels, transposition corresponds to reflection across a vertical line, and taking the adjoint means performing both of these operations.
We also classify the identity and SWAP maps as generators.

An important special case of this rule is the commutation relation between displacement operators $\hat{X}(a)$ and $\hat{Z}(b)$.

\begin{lemma}\label{lem:displacement_commutation_relation_zx}
    \begin{equation}
        \tikzfig{figures/qumodes/focked_up/pauli_webs/displacements_commute_red_green}
    \end{equation}
    \begin{equation}
        \tikzfig{figures/qumodes/focked_up/pauli_webs/displacements_commute_green_red}

        The first follows from the first equation of \Cref{lem:gate_copy_blank_spider}, with $f(x) = \overline{\chi}_a(x) = e^{i2\pi ax}$.

        \begin{equation}
            f(x + b) = e^{i2\pi a(x + b)} = e^{i2\pi ab}e^{i2\pi ax} = e^{i2\pi ab} \overline{\chi}_a(x)
        \end{equation}
        where the scalar $e^{i2\pi ab}$ can be pulled out of the spider to become a global phase.
        The second follows from the second equation of \Cref{lem:gate_copy_blank_spider}, with $f(x) = \chi_b(x) = e^{-i2\pi bx}$.
        So:
        \begin{equation}
            f(x + a) = e^{-i2\pi b(x + a)} = e^{-i2\pi ab}e^{-i2\pi bx} = e^{-i2\pi ab} \chi_b(x)
        \end{equation}
    \end{proof}
\end{lemma}

\subsection{The Gaussian + combs fragment}

We said earlier the CV analogue of Clifford unitaries are the Gaussian unitaries.
The CV analogue of the Clifford fragment of the qubit ZX-calculus is the Gaussian fragment.
This is exactly the space of diagrams generated by green and red spiders whose function labels are quadratics, plus the vacuum state.
That is, it's all diagrams generated by:
\begin{equation}
    \tikzfig{qumodes/prelims/zx/spider_green_quadratic}
    \qqqquad
    \tikzfig{qumodes/prelims/zx/spider_red_quadratic}
    \qqqquad
    \tikzfig{qumodes/prelims/zx/state_vacuum}
\end{equation}
We will in fact be interested in adding one more type of spider to the mix.
For any predicate $f: X \to \BB$, i.e.\ any function that returns true or false, let $\indicator{f(x)}$ be the function that's $1$ if $f(x)$ is true and $0$ if not.
Then also let $x \eqmod{r} c$ mean $x = c \text{ mod } r$.
So:
\begin{equation}
   \indicator{x \eqmod{r} c} =
   \begin{cases}
       1 &\text{ if $x = c \text{ mod } r$} \\
       0 &\text{ else}
   \end{cases}
\end{equation}
We call spiders with these labels \textit{comb spiders}:
\begin{align}\label{eq:green_and_red_comb_spiders}
    \tikzfig{qumodes/prelims/zx/spider_green_comb}
    \quad &= \quad
    \sum_{k \in \ZZ} \ket{c + kr}_Q^{\otimes m} \bra{c + kr}_Q^{\otimes l} \\
    \tikzfig{qumodes/prelims/zx/spider_red_comb}
    \quad &= \quad
    \sum_{k \in \ZZ} \ket{c + kr}_P^{\otimes m} \bra{c + kr}_P^{\otimes l}
\end{align}
The name comes from the fact that one-legged comb spiders are infinite sums of Dirac distributions $\ket{q}_Q$ (in the green spider case) and the Fourier transform of these $\ket{p}_P$ (in the red spider case).
The Dirac distribution $\delta_c$ is often informally pictured as the limit of the Gaussian curve $\delta_{c,\epsilon}(x) = (2\pi\epsilon)^{-1/2} e^{-(x-c)^2/(2\epsilon)}$ as $\epsilon \to 0^+$, i.e.\ as this gets narrower and taller.
Hence a sum of a regularly spaced set of such distributions as in the spiders below resembles a comb.
\begin{align}\label{eq:green_and_red_comb_states}
    \tikzfig{qumodes/prelims/zx/state_green_comb}
    \quad &= \quad
    \sum_{k \in \ZZ} \ket{c + kr}_Q \\
    \tikzfig{qumodes/prelims/zx/state_red_comb}
    \quad &= \quad
    \sum_{k \in \ZZ} \ket{c + kr}_P
\end{align}
