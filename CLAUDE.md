Notation: try to use    
- \mathcal for groups and vector spaces, e.g. \mathcal{P}, \mathcal{V}
- regular capital letters for matrices and linear maps, e.g U, V, A, B
- EXCEPTION: use X, Y and Z for the actual single qubit Pauli matrices, but \mathcal{X}, \mathcal{Z} and \mathcal{Z} for representatives of logical operators, that are themselves tensor products of Pauli matrices. e.g. \mathcal{X} = X_1 X_2 X_3.  
- \boldsymbol for vectors, e.g. \boldsymbol{\xi}
- \overline for cosets, e.g. \overline{\mathcal{X}} = \mathcal{X}\mathcal{S} \in \mathcal{N(S)/S}
- use $r$ for the rank of any stabilizer group
- Avoid triple dashes --- I prefer double dashes --
- use italics when defining an object embedded in the main text, or bold for an object being defined inside a definition environment (since the text here is already italicised!).
